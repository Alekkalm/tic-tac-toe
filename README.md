# Крестики-нолики (мультиплеер)

Простая сетевая игра «Крестики-нолики» на двоих игроков в реальном времени.
Сервер — авторитетный арбитр: вся игровая логика и проверка ходов происходит
на сервере, клиент только отправляет намерения и отрисовывает состояние.

## Стек

- **Node.js** — среда выполнения
- **Express** — раздача статики (папка `public`)
- **Socket.io** — WebSocket-соединение между клиентами и сервером

## Структура проекта

```text
tic-tac-toe/

└── public/
    ├── index.html # разметка и стили
    └── client.js # логика клиента (Socket.io)
```

## Как играть

1. Два игрока открывают игру в браузере.
2. Оба вводят **одинаковый ID комнаты** (например, `room1`).
3. Первый вошедший ждёт второго.
4. Когда второй подключается — игра начинается.
5. Игроки ходят по очереди: первый — `X`, второй — `O`.
6. Побеждает тот, кто первым соберёт три в ряд (по горизонтали, вертикали или диагонали). Если поле заполнено без победителя — ничья.

## Требования

- **Node.js** версии 18 или выше (проверить: `node -v`)
- **npm** (устанавливается вместе с Node.js)

## Установка и запуск

### 1. Установить зависимости

В терминале, находясь в корневой папке проекта:

```bash
npm install
```
Эта команда прочитает `package.json` и установит `express` и `socket.io` в папку `node_modules/`.

### 2. Запустить сервер

```bash
npm start
```

Если всё в порядке, в терминале появится:
```text
Сервер: http://localhost:3000
```

### 3. Открыть игру

Откройте в браузере два окна (или одно окно и режим инкогнито):
```text
http://localhost:3000
```

В обоих окнах введите одинаковый ID комнаты (например, `room1`) и нажмите **«Войти»**. Первое окно покажет «Ожидаем второго игрока…», второе — начнёт игру.

### 4. Остановить сервер

В терминале, где запущен сервер, нажмите `Ctrl + C`.

### Возможные проблемы

**npm: Невозможно загрузить файл npm.ps1...**

PowerShell блокирует выполнение скриптов. Решение — один раз выполнить
в терминале:

```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
```
Затем подтвердить (`Y`) и повторить `npm install`.


### Как это работает (кратко)

- При подключении клиент отправляет событие `join` с ID комнаты. Сервер через `socket.join(roomId)` объединяет сокеты в комнату.

- Первый игрок создаёт игру, второй — присоединяется, после чего обоим рассылается событие `start` с начальным состоянием.

- При ходе клиент отправляет `move` с индексом клетки. Сервер проверяет: это игрок данной комнаты? его ли сейчас ход? свободна ли клетка?

- Если ход валиден — сервер обновляет доску и рассылает `update` (или `gameover`, если игра завершена).

- При отключении игрока комната удаляется, второму приходит `opponent-left`.
